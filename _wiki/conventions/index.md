# Conventions

- [slide-patterns.md](slide-patterns.md) — no inline HTML layout, fragments and `. . .`, column sync, image swap, notes, dense slides, closing slide
- [math.md](math.md) — MathJax 2 macro syntax; `\cancel` and mathtools substitutes
- [theme-classes.md](theme-classes.md) — shared theme classes, palette; theme edits need approval
- [mermaid.md](mermaid.md) — sizing (`fig-width` + `fig-height`), styling, label rules
